# Software Rasterizer (C++ / SDL3)

Учебный проект: программный рендерер 3D-сцены в **ортогональной проекции** без OpenGL / Vulkan / DirectX.

SDL3 используется только для окна, ввода и записи в текстуру (framebuffer). Математика преобразований, растеризация треугольников, z-buffer и простое освещение реализованы самостоятельно.

## Возможности

- Загрузка сцен из Wavefront OBJ (`scenes/*.obj`)
- Собственные типы: векторы, матрицы 4×4, вершины, объекты
- Ортографическая проекция, viewport, повороты, масштаб
- Заливка треугольников + **z-buffer**
- Простое освещение по нормали (Lambert-like)
- Интерактивная камера

## Управление

| Клавиши | Действие |
|--------|----------|
| `W` / `S` | Поворот вокруг оси X |
| `A` / `D` | Поворот вокруг оси Y |
| `Q` / `E` | Поворот вокруг оси Z |
| Колёсико мыши | Масштаб |
| `R` | Сброс углов и масштаба |

Сцена по умолчанию: `scenes/8.obj` (меняется в `main.cpp` → `load_scene(...)`).

## Требования

- C++ компилятор (проект собирался с **g++ / MinGW** на Windows)
- [SDL3](https://github.com/libsdl-org/SDL/releases) (development libraries)

## Сборка (Windows + MinGW)

1. Скачайте SDL3 и распакуйте, например в `C:\SDL3-3.2.4\`.
2. В `MakeFile` поправьте пути `-I` и `-L` под свою установку SDL3.
3. Из корня репозитория:

```bash
make -f MakeFile
```

4. Запуск:

```bash
./main.exe
```

Рабочая директория при запуске должна быть корнем проекта (чтобы находился путь `scenes/...`).

### Пример строки линковки

```text
g++ <все .cpp> -o main.exe -IC:\SDL3-...\x86_64-w64-mingw32\include -LC:\SDL3-...\x86_64-w64-mingw32\lib -lSDL3
```

Рядом с `main.exe` может понадобиться `SDL3.dll` из поставки SDL3.

## Структура

```text
main.cpp              — точка входа (SDL callbacks)
headers/
  structures/         — vector, matrix, camera, object, ...
  funcs/              — загрузка сцены, пайплайн кадра, растеризация
  globals/            — глобальное состояние рендера
scenes/               — OBJ-модели
MakeFile              — сборка под MinGW + SDL3
```
